# vedit listen

Ad-hoc listening: what does the audio say around these times or splices.

Done when:
- [x] `vedit listen A 300 312` prints source-time words of an excerpt
- [x] `vedit listen --splice A 668.78:672.2 A 668.78:674.1` transcribes candidate splices in one pass
- [x] `vedit listen --program 412.5` reads around a program time
